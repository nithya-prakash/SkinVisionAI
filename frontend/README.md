# SkinVision AI — Frontend

Next.js (App Router) + TypeScript + Tailwind CSS.

See the [project README](../README.md) and [docs/](../docs/) for
architecture, safety boundary, and setup instructions. This app contains no
skincare logic — it only collects input and renders backend-validated
results.

```bash
npm install
cp .env.local.example .env.local
npm run dev -- --port 3010
```
